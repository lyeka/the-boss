# 我是大老板 · The Boss Club

《I'm the Boss!》中文浏览器数字桌游。3–6 个座位，自由组合真人与基础电脑玩家，支持同一台设备交接手牌、完整谈判与终局。深绿会所桌面、木质棋盘、黄铜棋子与原版投资人人像。

## 启动

当前工程实际验证环境：Node.js 22.20、npm 10.9。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认为 http://127.0.0.1:5173 。

```sh
npm test
npm run build
npm run preview
```

生产文件在 `dist/`，无需后端，包含本地字体、人像与 Web Audio 合成音效。通过 HTTP 静态服务打开；不要直接双击 `dist/index.html`。运行后没有在线 API、登录或 LLM 依赖。

## 怎么玩

1. 设置 3–6 个座位、名字、真人/电脑和电脑性格。默认一位真人与三位电脑。可展开规则变体。
2. 随机分配投资人和初始手牌。由起始玩家右手边的人放置棋子；该座位是电脑时会自动放置。
3. 自己回合选择“开始谈判”，或“掷骰移动”后再谈判/补牌。
4. 在右侧选投资代表、编辑各人分红并发送方案。对方可以接受、报价、打出替代团队、招募、旅行或抢老板。
5. 点击手牌选择具体目标。旅行、老板、招募出现 STOP 响应窗口，所有玩家均可反制；无意反制时点击“不使用 STOP”。
6. 达成协议后宣布成交。所有玩家确认不再干预，老板两次落槌，自动分配现金、清理卡牌、覆盖格子并移动棋子。
7. 本地多人随时点击真人座位交接设备。隐私遮罩阻断背景交互与辅助技术读取；只有当前座位手牌会绘制。电脑不会看到其他玩家的手牌。
8. 第 10–14 号交易后进行终局掷骰，第 15 号必定结束。资产最高者获胜；同额列为并列。

电脑可以暂停、调速或单步执行。自动保存每个动作；游戏菜单可导入/导出 JSON。导出内容包含完整隐藏状态，只适合备份与赛后复盘。浏览器刷新后需要先确认查看自己的手牌。

## 规则依据与数字化约定

主依据是用户指定的 [2023 原版规则 PDF](https://gamers-hq.de/media/pdf/26/0e/cf/ITB-Rules-public.pdf)，已逐页读取正文与插图，并将第 6 页完整谈判示例写为回归测试。

- **16 个格子不是随机生成**：数据来自该 PDF 内嵌、被示例剪裁隐藏的完整棋盘。保留所有多组条件，见 `reference/board-data.json` 和 `reference/extract-board.py`。
- **98 张影响力牌**：团队 24、旅行 21、招募 33、老板 10、STOP 10，逐张独立 ID；任何动作后验证总量、唯一性、现金守恒。
- **完整基础规则**：随机发牌、3 人双投资人、4/5 人公共投资人、必须先移动才能补牌、跳过已盖住格子、12 张上限与超限招募、公开团队竞争、永久招募、旅行特定对象、STOP 第三方保护/不可叠 STOP、连续抢老板、全部约定兑现、未使用团队回手、失败不移动/不补牌/不消耗交易号、弃牌重洗、最终老板决定下一回合、后期随机结束。
- **逐人确认落槌**：采用原书第 4 页明确列出的询问变体，让共用一台设备的玩家不会错失出牌机会。没有强制秒数倒计时。STOP 响应同样必须明确放弃才关闭。
- **金额**：以实体最小面额 $1M 为整数单位记账，可自由议价，不要求按整数份分红；银行自动兑换现金。未模拟 110 张纸币的逐张找零。
- **八个可选变体**：都可在设置中启用。温和谈判的“公平份额”在原书中没有数值公式，本实现明确约定“每个团队一份、老板一份，向下取整到百万，余数归老板”。它不是原书的额外条文，默认关闭。多变体同时开启时，强制成交只对同时满足付款资格的组合生效。
- **终局数字证据边界**：实现标准第 10–15 号的递增阈值 `[1,2,3,4,5,6]`。原 PDF 明确给出第 11 号 1–2、第 13 号掷 5 继续、第 15 号必结束；尚未取得新版每一张背面的逐张照片。不能声称六张新版背面均经独立照片核验。详见 `reference/verification-notes.md`。
- **2 人专用玩法**不列为可选人数，因为本阶段要求为 3–6 人；其规则通过原书“温和谈判”变体用于 3–6 人。

所有玩家可以在谈判/落槌阶段主动操作；响应窗口为一个待处理动作建立原子边界，不将自由谈判改为轮流出牌。

## 工程结构

```text
src/engine/types.ts       状态、动作、观察和 DecisionAgent 协议
src/engine/catalog.ts     16 格、98 张卡牌、分红曲线与变体
src/engine/game.ts        无 UI/浏览器依赖的确定性规则引擎
src/agents/basic.ts       只读取本人观察的基础电脑策略
src/ui/                  棋盘、座位、谈判、设置、规则和声音
src/App.tsx              本地调度、界面状态、存档与隐私交接
src/styles.css           会所风格、2.5D 材质、响应式与减少动态效果
public/assets/           本地人像、字体及字体授权文本
tests/game.test.ts       规则、官方示例、完整对局和边界测试
docs/ARCHITECTURE.md      MyGo/LLM 扩展点与状态机说明
reference/               原书、组件转录与研究证据
```

## 当前边界

基础电脑使用确定性启发式：选组合、要价/接受、公开团队、招募、部分旅行威胁、抢老板和防守；不理解自由文本，不使用 LLM，也不承诺达到真人谈判水平。本地存档有结构与守恒校验，不是防作弊的联网权威服务器。当前是本地同屏多人，不是跨设备联机。

MyGo 桌面壳尚未创建；静态产物和纯 TypeScript 引擎已为后续 WebView/Go 桥接留出清晰边界。
