# 原版组件核对

## 棋盘

`board-data.json` 的 16 格均直接取自用户指定 PDF 的嵌入原始棋盘绘图。
原 PDF 第一页仅展示一个交易格，但其内容流含完整棋盘；`extract-board.py` 将该图的剪裁范围放开，得到 `board-verified.png`。
该研究图被标题左侧少量原文覆盖，交易格数据全部可见。底边从左数第二格也与规则第 2 页上方示例完全对应。

数组 index 0 是原图左下角（红黄蓝必需，橙紫绿三选二），顺时针向左边上行、上边右行、右边下行、底边左行。
颜色：red 传媒、yellow 金融、blue 科研、orange 法律、purple 政治、green 科技。
每组 `count` 为该组必须选的不同团队数量。多组全部满足；同色不能重复计数。
特别注意 index 1 和 10 都是三个独立选择组，不能简化成一个任选池。

## 分红牌

金额序列（百万美元）：`[2,2,2,3,3,3,4,4,4,5,5,5,5,5,5]`。
证据：新版 PDF 图示 #1=2M、#6=3M、#7=4M、#15=5M，正文 #13=5M；新版实物组件图 #8/#9=4M。
旧版实物正面照片确认各金额起点 #1=2M、#4=3M、#7=4M、#10=5M，且 BGG 原照片评论明确逐段编号。
- https://boardgamegeek.com/image/293317/im-the-boss （`dividend-tiles.jpg`，实物照片，非2023美术版）
- https://www.gamenerdz.com/im-the-boss-2023 （`board-setup.png`，新版组件图）

## 终局骰子

原 PDF 明确：第10号牌起每次成功交易后掷骰；第11号为1或2结束；第15号自动结束；第13号掷出5继续。
已找到旧版背面实物“1–3结束”的照片（`end-tiles.png`），但该单面照片不显示交易序号。
标准递增阈值为第10..15号 `[1,2,3,4,5,6]`。除第11号及第15号外，尚未找到2023版每张正反面一一对应的全套图片；将此序列视为与规则递增及已确认样例相符的补全，不能声称六张背面均已逐张核验。
