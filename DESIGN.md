# The Boss Club

User confirmed: 复古商务会所，深绿与黄铜。
A single physical negotiating table is the main surface. The app opens directly to the table, with a new-game sheet for seats. Green felt, brown walnut rim, warm brass, ivory cards, generous dark surroundings. No marketing landing page.
The full 16-space board remains visible. Players surround the board; the current deal and negotiations live to the right; private hands along the bottom. Cards lift on hover. Brass money marker advances clockwise. Settlement seals the actual board space.
Typography: Georgia for English display and money, Noto Serif SC/Chinese serif for Chinese display, system Chinese sans for controls. Labels remain legible and descriptive. Shape + icon + color identify each investor.
Desktop 1440+ has full table and side ledger. Tablet uses compact board and ledger. Phone has horizontally scrollable board and stacked controls. Reduced motion disables travel/flip animations; all actions keyboard-accessible.
